# Agent HQ

Build a polished executive demo application called “Agentic Telecom & Media Company HQ.”

This application is the executive front door to a portfolio of already-built agentic AI demos for a large telecom and media company. Assume each underlying agentic solution has already been built and published externally. This HQ app should organize those agents into “rooms of the house,” show how they work together as an enterprise agent ecosystem, and allow users to launch each individual agent demo from its card.

The app should feel like a premium Microsoft-style executive command center for a telco/media company. It should not feel like a simple link directory. It should feel like an AI Operating Model, AI Agent Marketplace, and executive control tower for the entire agentic enterprise.

Use mock data only. Do not require real integrations.

Important:

- Each agent card should include a “Launch Demo” button.

- The launch button should open the relevant published demo in a new browser tab.

- If iframe embedding is possible, provide an optional “Preview in Hub” modal, but the default should be opening the demo externally because some published apps may block embedding.

- All agent URLs are provided below as Markdown links.

- Use modern executive UI design with strong visual hierarchy, rounded cards, subtle shadows, dark navy / white / Microsoft blue / teal / green / amber / red accents.

- Include animations showing agents communicating across rooms.

- Include Microsoft architecture, Agent365 governance, AI Marketplace, ROI dashboards, and executive walkthrough mode.

Application Concept:

“Agentic Telecom & Media Company HQ” should show that a telecom/media enterprise can organize AI agents across every major business function: Network, IT, Media, HR, Consumer, Business, Finance, Legal, and Procurement. Each room contains specialized agents. The executive layer sees business outcomes, ROI, governance status, adoption, and cross-functional signals.

Use the metaphor:

“The rooms of the AI-powered telecom company.”
